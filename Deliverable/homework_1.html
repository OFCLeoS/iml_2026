Part 1: Partial Derivatives¶

(a)¶

Compute the derivative $\partial L / \partial x(i).$ Leaving all other variables fixed, what value of $x(i)$ minimizes $L$?

$$\frac{\partial L}{\partial x(i)}=\sum_{i=1}^{N}\frac{\partial}{\partial x(i)}|\mu-x(i)|+\lambda y^2$$ $$=\sum_{i=1}^{N}sgn(\mu-x(i))(-1)+0$$ $$=\sum_{i=1}^{N}-sgn(\mu-x(i))$$ Since all other sum terms are not for x(i): $$=-sgn(\mu-x(i))$$ Since for x(i) only $|\mu-x(i)|$ changes L, we want to minimize it, which can be achieved with: $$x(i)=\mu$$

(b)¶

Compute the derivative $\partial L / \partial \mu.$ If $\lambda = 0,$ what values of $\mu$ minimize $L$?

$$=\sum_{i=1}^{N}\frac{\partial}{\partial(\mu)} |\mu-x(i)|+\lambda\mu^2$$ $$=\sum_{i=1}^{N}sgn(\mu-x(i))1+2\lambda\mu$$ $$=\sum_{i=1}^{N}sgn(\mu-x(i))+2\lambda\mu$$ If we set $\lambda=0$,then: $$=\sum_{i=1}^{N}sgn(\mu-x(i))$$ To minimize L, the derivate must be 0. we expand the sum. $$=sign(\mu-x(i))+sgn(\mu-x(2))+...+sgn(\mu-x(N))$$ Each "sgn" is either -1 or 1: $\mu>x(i)=>1$,$\mu<x(i)=>-1$

RESPONSE: We pick the median of the values (L derivation will be 0)

Example:

X={1,2,3}=>N=3, right of $\mu=2$ $$\frac{\partial L}{\partial \mu}=sgn(\mu-1)+sgn(\mu-2)+sgn(\mu-3)$$ $$=1+1-1=1$$ X={1,2,3}=>N=3, left of $\mu=2$: $$1-1-1=-1$$

So in this example, we would pick $\mu=2$.

Compute the derivative $\partial L / \partial \theta.$

$$L=\sum_{i=1}^{N}|\theta^3-x(i)|+\lambda\theta^6$$ $$\frac{\partial L}{\partial\theta}=\sum_{i=1}^{N} \frac{\partial}{\partial\theta}(\theta^3-x(i))+\frac{\partial}{\partial\theta}\lambda\theta^6$$ $$=\sum_{i=1}^{N} [sgn(\theta^3-x(i))3\theta^2]+6\lambda\theta^5$$ $$=\sum_{i=1}^{N} 3\theta^2(sgn(\theta^3-x(i)))+6\lambda\theta^5$$ Result: $$ \partial L / \partial \theta = 3\theta^2[\sum_{i=1 }^{N }sgn(\theta^3-x(i))+2\lambda\theta^3]$$

Compute $$ \frac{\partial}{\partial z_i} \ln \operatorname{softmax}(z)_j. $$ (Hint: first define $Z = \ln \sum_{j = 1}^k e^{z_j}$ and compute $\partial Z / \partial z_j.$)

Consider the linear model, defined by parameters $(\theta_0, \theta_1)$, which predicts $$ \hat y(i) = \theta_0 + \theta_1 x(i) $$ for each index $i.$ Express the gradient $\nabla L$ of mean squared error as a function of the parameter vector $\theta$ and the datapoints $(x(i), y(i)).$

Using what we know $$\hat y(i) = \theta_0 + \theta_1 x(i)$$ $$L=\frac{1}{N}\sum_{i=1}^{N}((\hat y(i)-y(i))^2)=\frac{1}{N}\sum_{i=1}^{N}(\theta_0+\theta_1x(i)-y(i))^2$$ let's calculate the function $$\nabla L=\begin{bmatrix} \frac{\partial L}{\partial \theta_0}\ \frac{\partial L}{\partial \theta_1} \end{bmatrix}$$ with: $$\frac{\partial L}{\partial \theta_0}=\frac{2}{N}\sum_{i=1}^{N} (\theta_0+\theta_1x(i)-y(i))$$ and $$\frac{\partial L}{\partial \theta_1}=\frac{2}{N}\sum_{i=1}^{N} (\theta_0+\theta_1x(i)-y(i))x(i)$$

from iml import SimpleRegressor


class GradientDescentRegressor(SimpleRegressor):
    def __init__(self):
        self.weights_ = np.zeros(2)

    def predict(self, x):
        return self.weights_[0] + x * self.weights_[1]

    def fit(self, x, y, lr: float, steps: int = 20) -> None:

        self.x_train_ = x.copy()
        self.y_train_ = y.copy()
        self.y_predicted_ = np.zeros((steps + 1, y.shape[0]))
        self.y_predicted_[0] = self.predict(x)

        for i in range(steps):
            # Gradient of MSE with respect to [intercept, slope]
            errors = self.y_predicted_[i] - y

            gradient_theta0 = 2 * np.mean(errors)
            gradient_theta1 = 2 * np.mean(errors * x)

            self.weights_[0] -= lr * gradient_theta0
            self.weights_[1] -= lr * gradient_theta1

            self.y_predicted_[i + 1] = self.predict(x)

import numpy as np
import random

def lloyd_forgy(data, k, max_iterations=500):
    # Max Iterations to avoid infinite loop
    # 1. Initialize Centroids (Pick random ah points)
        # 1.1. Assign each data point to nearest centroid
        # 1.2. Update centroids to mean of the points within it
        # Repeat until no more assignments to a data point is done or max iterations have been reached (to avoid infinite loop)

    # 1.
    # We initialize the centroids, and
    # The centroids dictionary (maps a centroid to an array of data points that belong to said centroid)
    # The data points dictionary (maps a data_point str to a centroid index)
    centroids = []
    centroids_dict = {}
    data_points_dict = {}
    for i in range(k):
        index = random.randint(0, len(data)-1)
        centroids.append(data[index])
        centroids_dict[i] = []

    repeat = True
    iterations = 0
    # We repeat until no more assignments to a data point is done
    while repeat and iterations <= max_iterations:
        repeat = False
        # 1.1
        for data_point in data:
            # We start with a big number as a reference (max 32bit integer)
            closest_centroid_distance = 2147483647
            closest_centroid_index = -1
            for i in range(len(centroids)):
                distance = get_euclidean_distance(data_point, centroids[i])
                if distance < closest_centroid_distance:
                    closest_centroid_distance = distance
                    closest_centroid_index = i
            
            # 1.2
            if str(data_point) in data_points_dict and data_points_dict[str(data_point)] != closest_centroid_index:
                key = data_points_dict[str(data_point)]
                repeat = True
                # TODO: Exit on spotting the entry? (this scans the whole list)
                centroids_dict[key] = [entry for entry in centroids_dict[key] if not (entry == data_point).all()]   
                centroids_dict[closest_centroid_index].append(data_point)
                data_points_dict[str(data_point)] = closest_centroid_index
            elif str(data_point) not in data_points_dict:
                repeat = True
                centroids_dict[closest_centroid_index].append(data_point)
                data_points_dict[str(data_point)] = closest_centroid_index
        # If repeat is not True, then no assignment was made, and we do not need to update the centroid mean
        if repeat:
            for i in range(len(centroids)):
                # Centroid will be new average of points that are assigned to it
                centroids[i] = sum(centroids_dict[i])/len(centroids_dict[i])
        iterations += 1

    # print(f"FINISHED IN {iterations-1} ITERATIONS")
    return data_points_dict

# We did this helper method to help us with lloyd forgy
def get_euclidean_distance(start, end):
    if len(start) != len(end):
        raise ValueError(
            "Euclidian Distance Error: The 2 points need to be of the same length.")
    euclidian_distance = 0
    for i in range(len(start)):
        euclidian_distance += (start[i]-end[i])**2
    return euclidian_distance
